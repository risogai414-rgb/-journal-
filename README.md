# ジャーナル（フェーズ1）

毎朝30秒で記録する、個人用のジャーナリングPWA。素のHTML/CSS/JSのみ、ビルド不要、バックエンドなし。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の枠と下部タブ |
| `app.js` | 全ロジック（日次入力・月間ビュー・月次メモ・設定・JSON入出力・ダミーデータ） |
| `style.css` | 見た目（方眼背景・ダークモード） |
| `manifest.webmanifest` | ホーム画面追加用の設定 |
| `sw.js` | オフラインでも開けるようにするキャッシュ |
| `icons/` | アプリアイコン |

## データ

ブラウザの localStorage（キー `journal.data`）に1つのJSONで保存。

```json
{
  "schemaVersion": 1,
  "settings": { "habits": [{ "id": "h1", "name": "ジャーナリング" }] },
  "days": { "2026-11-01": { "habits": { "h1": true, "h2": 0.5 }, "satisfaction": 7, "weight": 65.2, "kcal": 1850, "focusHours": 1.5, "highlight": "…" } },
  "months": { "2026-11": { "goal": "…", "focus": "…", "keep": "…", "problem": "…", "try": "…" } },
  "meta": { "lastExportAt": "…" }
}
```

- 習慣は `true`=できた（黒塗り）、`0.5`=まぁまぁ（半分塗り）、記録なし=未達。達成率では0.5回として数える
- 習慣はIDで記録しているので、名前を変えても過去データはそのまま。「外す」は非表示にするだけで記録は消えない
- 設定 → 「JSONをエクスポート」でバックアップ、「インポート」で復元（置き換え）

## ローカルで動かす

```sh
cd journal-pwa
python3 -m http.server 8000
```

PCのブラウザで http://localhost:8000 を開く。スマホ表示を見たいときはChromeの開発者ツールで端末表示に切り替える。
（`index.html` を直接ダブルクリックでも動くが、オフライン機能は http で開いたときだけ有効）

## iPhone（Chrome）でホーム画面に追加する

1. iPhoneのChromeで公開URLを開く
2. アドレスバー右の **共有ボタン（□に↑）** をタップ
3. **「ホーム画面に追加」** をタップ（見当たらなければメニューを下にスクロール、または「その他」から）
4. 名前を確認して「追加」

※ iOS 16.4以降が必要。ホーム画面のアイコンから開いたアプリと、Chromeのタブで開いたページは**別々にデータを持つ**ので、記録は必ずホーム画面のアイコンから行うこと。

## 更新するとき

ファイルを変えたら `sw.js` の `CACHE` の番号（`journal-v1` → `journal-v2`）を上げる。アプリを2回開き直すと新しい版になる。
